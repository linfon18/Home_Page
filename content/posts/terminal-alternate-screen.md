第一版终端用一列 DOM 节点做滚动记录。跑 `sl` 时如果每一帧都追加到记录区，几十秒后里面全是小火车，之前输入的命令都被挤出去了。我给前台的 `sl` 和 `top` 单独放了一个 `<pre>`，运行时隐藏滚动记录，退出再显示它。

## 火车在字符坐标里移动

`train()` 根据容器宽度和字号估计有几列。每帧把 `x` 左移一列，并替换轮子和烟雾。右侧从容器边缘进场时给车身加空格；车头已经越过左侧时改用 `row.slice(-x)`。所有行最后再按列数裁切一次。一帧只更新整个 `<pre>` 的文本，没有新增滚动节点，也不用为每个字符创建元素。

```js
const crop = (row, x, cols) =>
  (" ".repeat(Math.max(0, x)) + row.slice(Math.max(0, -x))).slice(0, cols);

for (const x of [6, 4, 0, -2, -5])
  console.log(JSON.stringify(crop("TRAIN", x, 6)));
```

五帧依次得到 `"      "`、`"    TR"`、`"TRAIN"`、`"AIN"` 和 `""`。可以把终端缩到手机宽度，检查左右两侧有没有被字符宽度估计切错。估计使用 `字号 × 0.61`，更换字体或加载回退字体时要再测一次。

## 把输入交还给提示符

程序开始时接管输入，`apt` 的确认态可以读一行回答，`top` 监听 `q`，`sl` 只刷新画面。几个程序共用一个可取消的定时器。`finish()` 清掉它、移除 `<pre>`、恢复记录和 shell 提示符。Ctrl+C 走同一条退出路径并设置状态码 130。网页隐藏时延后下一帧，不追补藏在后台的帧数。

我会用 `echo before`、`sl`、Ctrl+C、`echo $?` 检查这一链。回到提示符后第一行记录还在，状态码是 130，并且旧火车不再更新。第二次再跑完整动画，应该自然退出并回到 0。终端里的文件和安装状态都保存在 JS 对象中，页面没有运行系统命令。
