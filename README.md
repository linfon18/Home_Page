# linfon18 的小站

首页由竖排个人介绍、Linux 操作模拟终端、MinecraftConnectTool 入口和最近更新组成。文章、笔记、项目、日常、关于和联系方式各有独立页面，保留原来的简介、项目链接、社交账号和背景插画。项目页只突出 MinecraftConnectTool，另两个小工具保留在下方。

## EdgeOne 静态部署

只需要预装的 Node.js 14+。没有 npm 依赖，不安装框架，不需要 Python、sudo 或全局写入。

| 配置 | 值 |
| --- | --- |
| 框架 | Other |
| 根目录 | ./ |
| 安装命令 | bash 部署.sh install |
| 构建命令 | bash 部署.sh build |
| 输出目录 | dist |

仓库根目录的 `edgeone.json` 已固定以上构建命令、`dist` 输出目录及 Node.js 14.21.3，部署时会覆盖控制台对应设置。`deploy.sh` 兼容相同参数。旧项目在控制台手动配置时，输出目录也应填写 `dist`。

首页由构建生成在 `dist/index.html`，不提交到仓库根目录。构建成功后仍看到旧版 404 时，检查是否错误地发布了仓库根目录：如果 `/dist/index.html` 能打开而 `/` 不能，说明发布目录没有指向 `dist`。修改配置后需要重新部署。所有路由都有独立 HTML，可直接访问和刷新，不需要 SPA 回退或后端。

构建会同步 GitHub 头像，并生成内嵌该头像的 256×256 圆角 SVG favicon，圆角半径 64px。网络不可用时使用仓库内的真实头像快照。页面也会尝试从公开 API 同步头像，无需 Token。

## 站内切页

普通站内链接通过 fetch 读取静态 HTML，替换正文、SEO 元数据和导航选中状态，顶部显示细加载条。导航、鼠标和 Live2D 实例跨页保留；后退与前进恢复页面和滚动位置。页面模块在切走时清理请求、计时器及监听。直接访问和刷新仍使用独立静态 HTML；新部署资源版本不一致时完整加载新文档。

页头滚动收缩保持外层高度不变，仅移动内部导航，避免高度变化触发滚动锚定后在阈值处反复闪动。

项目页与 MCT 笔记列出 OpenP2P、MCILM-Link 和 EasyTier 去中心化组网三种方案。`Introduction.md` 保留原站归档内容。

## 文章与笔记

长文章放在 `content/posts/`，笔记放在 `content/notes/`。每个 Markdown 文件生成一个页面；文件名使用小写英文、数字和短横线。文件头格式如下，不需要引号：

```markdown

category: 学习记录
date: 2026-11-15
updated: 2026-11-15
tags: C#, 网络
draft: false
---

正文。

## 一个小节

正常写 Markdown。
```

`title`、`description` 和 `category` 必填；日期、更新日期、标签和草稿字段可选。日期格式为 YYYY-MM-DD。设置 `draft: true` 后，页面、索引、搜索、RSS 和 sitemap 都不会发布这篇内容。有日期的内容按日期倒序排列，未填写日期的内容放在后面。

新增或修改 Markdown，提交 Git 后让 EdgeOne 重新构建即可。无需手动添加路由、索引、目录或搜索数据。搜索收录全文、标题、简介、分类和标签；导航搜索按钮或 Ctrl / ⌘ K 可以打开搜索，索引页支持分类和 `/` 快捷键。

正文支持标题、段落、HTTP(S) 链接、加粗、行内代码、围栏代码块、列表、引用和分隔线。阅读页自动生成小节目录。原始 HTML 会转义。

目前包含个人站重构技术复盘（2026-11-15）、渲染性能排查（2026-11-16）、MCT 连接方式笔记和本站部署文章。性能文章位于 `/articles/weather-rendering-performance/`，记录样式重算、Cubism 缓存、挂滴供水模型和测量边界；重构复盘保留初版实现的历史说明，后两篇说明文未填写发布日期。

## 设计与交互

导航、个人名片、内容面板和阅读区域使用随亮暗主题切换的半透明底色与单层细边框。已移除全屏 WebGL 折射画布、导航的复制画布、厚重的亮边、内侧高光和面板模糊，只保留平整的透明层。Live2D 仍使用自己的独立画布。

主题支持浅色、深色和跟随系统，会记住偏好。另有入场动画、按钮涟漪、可选交互音和聚焦时钟。声音默认关闭，聚焦用 Esc 退出。

背景有缓慢移动的星点、近邻连线、指针牵引、短暂流星和点击扩散；导航指示跟随鼠标、焦点和当前页面滑动。页面切换、文章列表、联系卡片和阅读标题分段入场，头像轨道、名字末尾的点和签名下划线也有细微动效。`site/assets/effects.js` 和 `effects.css` 管理这些效果，不参与面板材质绘制。手机减少粒子数量和绘制频率；页面进入后台或打开对话框时停止背景绘制，开启“减少动态效果”时隐藏背景动画并停止入场动效。

流星随机选择出场间隔、起点、斜落方向、速度和尾迹长度，带轻微加速、头部亮点与渐隐尾迹；没有固定周期的整段动画重播。后台暂停时不累计流星，返回页面不会集中补发。

终端输入 `rm -rf /*` 触发短暂蓄光、单次暖色闪光、双层冲击波、碎屑和升腾云团，同时触发蓝龙生气。效果约 6.5 秒结束，重复触发不会叠加画布，切入后台立即清理。系统减少动态效果时只显示短暂静态色层。命令只触发站内彩蛋，不删除网站内容或浏览器存储。

GitHub 数据来自公开 API；接口受限时显示一天内的本机缓存，或明确显示不可用。不会用随机数字替代。头像请求失败不影响个人内容。

## 首页交互

桌面端有缓动鼠标圆环，移到链接或按钮时贴合其圆角轮廓；按钮有轻微磁吸，文章入口保持固定命中区域。指针驱动背景视差，按钮点击产生短暂波纹。头像、介绍分段入场，文章预览滚动出现。终端模拟一位 Linux 用户持续操作，右上角可暂停或继续。

终端是本地视觉模拟，包含 gcc 编译与报错纠正、gdb 断点/变量/调用栈、vi/vim 编辑、sudo 隐藏密码、apt 更新安装、日志跟踪、top、ip/ping、sl 蒸汽小火车和 clear。采用持续的状态变化、场景洗牌与参数生成，不是固定录像反复重播。命令会停顿、拼错后退格、移动光标插入修正、Tab 补全和回看历史；vim 有 NORMAL / INSERT 模式、行号、状态栏和保存退出过程。

滚动记录有上限，进入后台暂停推进。开启“减少动态效果”时默认暂停，可主动播放；触摸端不显示自定义鼠标。终端的命令、主机数据和密码过程都是演示，不会连接服务器或执行系统命令。关闭 JavaScript 仍可阅读首页与文章；页面半透明层无需 WebGL。

鼠标保留系统指针，外侧附加跟随圆环。终端使用固定深色控制台配色，移入后在当前命令行接管输入，不清空已有输出；离开五秒后静默继续原场景，手动暂停状态优先。手机点按后持续接管，弹出键盘、失去焦点、输入法组合输入和滚动都不会启动恢复；点按终端外部才开始五秒计时。键盘也可以通过 Tab 聚焦。输入 `help` 查看命令，支持历史、嵌套路径补全、Ctrl+C、Ctrl+L、gdb 和简化 Vim；编辑仅保存在当前页面内存。`ping` 按时间逐包输出，支持 `-c`、`-i` 和 Ctrl+C，延迟、丢包和统计为本地模拟。

自动场景包含 gcc/gdb/vi/vim、apt/sudo、sl、日志、top、网络、Git、systemctl、tar、chmod、awk/find、Docker、curl、make/readelf、tmux/crontab/vmstat 和 Python 检查，场景洗牌并持续变更参数。

新增八组连续操作：Nginx 配置报错与恢复、rsync 试运行与传输、DNS 解析排查、strace/ldd、CMake/CTest、脚本权限修复、访问日志管道分析、Git 分支提交。每轮从洗牌队列取出四组额外操作，搭配代码编辑、编译和调试；新一轮会改变参数和分支名称。

交互命令支持 `|`、`>`、`>>`、`<`、`&&`、`||`、`;`、引号、变量和退出码。文件操作会影响后续 `tree`、`cat`、`find`、`grep`、`sed` 和编译；`gcc -o` 记录编译时的参数，修改源码后需要重编译才会影响已有程序。`tar` 保存内存文件快照，`sha256sum` 计算文件内容的 SHA-256。`git add`、`commit`、`restore` 保留暂存和提交状态。服务启停会影响 `ps`、`ss`、`journalctl` 与本地 `curl` 响应。GDB 支持编号断点、禁用/删除、临时断点、局部变量、修改变量和程序退出状态。这些都是有限的本地命令语义，不是完整 Linux 环境，也不支持任意程序、脚本或远程连接。

可以直接尝试：

```sh
mkdir -p notes/demo && printf "red\nblue\nred\n" > notes/demo/colors.txt
cat notes/demo/colors.txt | sort | uniq -c
sed -i 's/1200/2400/' probe.c
gcc -g probe.c -o build/custom && ./build/custom
sudo systemctl stop nginx; curl -I http://localhost:8080
sudo systemctl start nginx; curl -I http://localhost:8080
git add probe.c && git commit -m "tune timeout"
```

前台程序共用终端的整个显示区。悬停冻结原画面，点击空白处可以直接输入，拖选输出仍能复制。真正输入后才接管，退出交互后恢复原场景，避免自动火车或编辑器与交互内容上下叠放。手动 `sl` / `sl -l` 有横向移动、烟雾和轮组帧；`top` / `htop` 定时刷新，`q` 返回。Ctrl+C 可结束前台程序，切页时清理其计时器。

长按 Enter 按键重复生成空提示符，不写入历史，也不改变退出码；GDB 空回车重复上一条调试命令。支持 Ctrl+A/E 移到行首/行尾、Ctrl+U/K 删除前后内容、Ctrl+W 删除前一个词。输入法组合期间的回车不会提交。

`apt` 使用有限包目录，区分已安装、新安装和不存在的包。`mkdir` 是 coreutils 提供的命令，不存在同名安装包；Java 可尝试 `sudo apt install openjdk-21-jdk`。安装和卸载需要 sudo，有确认、可中断进度及安装状态。`sudo --help`、错误选项和 shell 内置命令分别处理；`gcc` 区分缺少输入、标准输入参数错误、对象文件和可执行文件。这些行为仍属于本地模拟。

## 天气

全站页脚的天气入口提供自动、下雨、大雪、雾霾、冰雹、晴天和关闭。自动模式从 `https://wttr.in/?format=j1&lang=zh` 读取当前天气，默认使用请求 IP 所在地，也可填写城市；不申请浏览器定位权限。约每 20 分钟更新，接口失败会标明缓存，超过两小时的数据停止驱动效果。请求 12 秒超时，失败五分钟后重试；手动与关闭模式不发天气请求，选择保存在当前浏览器。

雨、雪、低浓度雾层和带落地反弹的冰雹由独立 Canvas 绘制，不拦截点击，也不改变面板材质。手机降低粒子数和绘制频率；后台、对话框和系统减少动态效果会暂停绘制，关闭后停止动画调度。天气与设置跨站内切页保留。雾霾是视觉选项，不表示空气质量或 PM2.5 测量；自动模式识别 wttr.in 的雾、霭及降水编码，冰粒对应冰雹视觉效果。

终端作为挡雨、挡雪的实体：雨滴跨越顶沿时产生短促溅水，顶沿的湿润区域扩散成薄水膜，积水汇到两侧后形成断续水痕，绕过圆角、短暂停滞、合流。两个下角分别蓄水，先挂滴、增大、拉长细颈，达到体积阈值后脱落；顶沿积水和持续供水充足、水路贯通后才转成连续细流，供水减少又退回滴落。终端内部从天气层中裁掉，不影响内容与输入。水滴采样缓存的背景图做局部放大与透明折射近似，不截图正文，也不为每滴水创建背景滤镜。大雪会在顶沿逐渐堆积，落点带来局部起伏，厚度与活动水痕数量都有上限。滚动和缩放重新测量边界，离开首页丢弃旧终端状态，切换天气清理对应积水与积雪。

Live2D 在雨、雪和冰雹模式撑伞，伞柄跟随原模型的手部网格，伞顶对齐头部上方，撑伞时调整手臂，选中文字用放大镜或生气时暂时收伞。雨滴在伞面被截住、积水从伞檐滴下；雪随碰撞在伞面堆积；冰雹撞伞后弹开。伞为独立 SVG 配件，没有修改蓝龙模型素材；配件不拦截点击，跟随角色缩放和跨页保留。系统减少动态效果、关闭天气或打开对话框时隐藏天气配件。

`viewport-canvas.js` 按画布实际 CSS 矩形设置缓冲区与坐标变换，避免滚动条占位把雨水、雪沿、星空或爆炸横向压缩。支持两侧预留滚动条槽，尺寸变化后重算，静止时缓存；碰撞与绘图共用视口坐标。

### 渲染性能

鼠标视差直接更新背景元素的 transform，不再把每帧变化的 CSS 变量写到根节点；按钮位置按布局变化缓存，读取和写入分开，卡片保持固定命中区域。已移除没有可见效果的旧面板高光监听。星空保留原粒子数量、连线距离和绘制频率，远距离配对先用距离平方排除。

`live2d-performance.js` 为当前固定版本的 Cubism 渲染器缓存每个网格的 UV 和索引缓冲，只上传变化的顶点，省略相邻网格重复的 GPU 状态设置。Framebuffer 的绑定状态由同一上下文中的绑定和删除操作维护，替代每帧向 GPU 同步查询。保留全部网格、遮罩尺寸、画布像素预算、分辨率与帧率；销毁和 WebGL 上下文丢失会清理缓存。角色交互仍由本站控制器处理，关闭了 Pixi 额外的鼠标轮询 ticker。终端在暂停、手动输入、后台和视口之外等待事件唤醒，替代每 60ms 检查一次状态。

性能验证使用相同视口、DPR 和特效设置对照浏览器主线程耗时；另对默认和 MAX 尺寸的桌面、手机角色做缓存开关前后逐像素比较。这些检查不能直接换算为具体笔记本的功耗或风扇转速。

开发验证脚本与运行方法在 `tests/README.md`；本轮基线和最终原始记录在 `docs/performance/`。本轮基线是优化前的本地工作版本，包含早期圆珠雨滴，不是线上历史提交。最终记录中鼠标移动的主线程任务耗时按窗口归一约降低 54%，下雨约降低 3%（幅度较小），静置未测到稳定改善；不据此承诺整机功耗或风扇噪声。

## 一言与 Live2D

首页页脚的名字旁显示一言，点击句子或使用键盘回车可以刷新。`site/assets/hitokoto.js` 从 `https://v1.hitokoto.cn/` 读取句子和出处；当前会话缓存最近一次成功结果，接口失败或超时保留原句。首次加载没有缓存时显示个人签名。简介中的称呼为 linfon18 / Ad1va。

蓝龙位于页面右下角，桌面和手机均可显示，加载后会先打招呼，鼠标靠近时主动留意你。平时轮换张望、歪头、伸展、抖耳、轻哼和打哈欠，搭配视线跟随、眨眼、呼吸和尾翼动作。终端自动出现 sl、gcc、gdb、vim、网络和 apt 场景时，会分别作出惊喜、得意、好奇等反应；切换主题和离开页面一段时间后回来也会有回应。主动反应带有冷却时间，手动互动优先。

点击头部、脸、耳朵、身体或翅膀会轮换对应动作；在头上来回移动鼠标可以摸头，双击出现爱心眼，连续戳五次会晕头并稍作恢复。长按会根据部位触发蹭头、挥手、伸展或不满的表情。鼠标按住角色可以拖动，手机从头部或身体中间起手；拖动时会倾身，松手有落地动作。位置跨页和刷新保留，大小菜单里的“恢复默认”会一并移回右下角。动作直接驱动模型参数，画布透明边角仍可点击下面的页面。聚焦角色后，回车摸头，空格扇翅，方向键触发表情，Shift 加方向键移动角色。

桌面选中正文文字后，蓝龙会侧头观察选区，手里出现放大镜，镜片显示所选文字。SVG 放大镜通过模型手部网格定位，随手臂运动；没有修改原模型素材。选区保留原生复制功能，不读取输入框或终端里的选区。清空选区、切页、关闭角色或打开对话框会收起放大镜；动作也会自行结束。减少动态效果时保留静态反应。

联系页在桌面使用两栏，左侧保留 GitHub、QQ 和 Bilibili，右侧整理 MCT 反馈入口、版本和网络信息及日志清单，可以复制反馈模板。窄屏改为单栏。

手机端自动加载同一模型，在右下角缩小显示，点按角色不同部位即可互动，透明区域仍可滑动和点击页面。关闭按钮的触摸区域为 44×44px，关闭后可以从页脚 Live2D 按钮恢复，偏好跨页记忆。手机和触摸设备的绘制上限为 30fps，桌面为 36fps；画布按设备像素密度与页面缩放渲染，最高 4 倍，另设手机 300 万、桌面 400 万画布像素上限。Cubism 遮罩使用 512 或 1024 像素，避免只提高画布分辨率而放大后边缘仍模糊。切换显示器、页面缩放、关闭弹窗后也会同步画布尺寸。减少动态效果时静态显示并支持短暂的静态表情互动，页面隐藏或弹出对话框时暂停。

角色旁的缩放按钮或页脚“大小”可打开设置，支持 50%–200% 滑块、每次 10% 的加减按钮、恢复默认和 `MAX`。MAX 按当前可视屏幕尽量放大，随横竖屏、窗口和软键盘变化重新计算，并保留控制按钮空间；再次点击 MAX 或调整滑块、加减和默认按钮可退出。聚焦角色后也可用 `+`、`-` 和 `0` 调整。大小和 MAX 偏好存入本地，切页和再次打开网站后继续使用，不重建模型；放大仍受画布像素预算约束。

蓝龙并非 linfon18 自己的原创角色设计，Live2D 来源为 [Bilibili 视频 BV13Mg66xEAa](https://www.bilibili.com/video/BV13Mg66xEAa)，全站页脚和改版文章中也保留了来源链接。来源记录在 `docs/live2d-source.md`，压缩包内的使用须知原文保存在 `docs/live2d-model-notice.txt`。模型资源位于 `site/assets/live2d/blue-dragon/`；PixiJS 6.5.10、pixi-live2d-display 0.4.0 和 Cubism Core 运行库保存在 `site/assets/vendor/`，相应许可文件和原始声明随源码保留。构建不需要安装这些库。

终端输入 `rm -rf /*` 或加 `sudo` 的同类命令，会触发蓝龙生气及核爆、冲击波彩蛋，随后恢复。效果由 `catastrophe.js` 和 `catastrophe.css` 绘制，不执行命令、不删除文件。减少动态效果时使用短暂静态光晕。鼠标进入终端只暂停推进，保留现有输出节点、位置和提示符颜色，真正输入时才更新命令行。
